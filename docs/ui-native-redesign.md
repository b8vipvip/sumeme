# SuMeMe 原生客户端与服务端 UI 重构

状态：实施中

## 产品边界

- Android/Windows 客户端使用 Flutter 原生组件，不再以 WebView 作为主界面。
- `sumeme.mv3.cn` 是独立部署的 SuMeMe Web 服务端入口。
- LobeHub 不再作为产品 UI、品牌或客户端运行时依赖。
- 客户端只通过经过认证的 HTTP API 与服务器通信。

## 客户端信息架构

1. 首页：服务状态、最近记忆、待同步、最近文件。
2. 对话：会话列表、消息流、模型选择、附件和记忆开关。
3. 记忆：搜索、时间线、标签、人物/项目/地点筛选、编辑与删除。
4. 资料库：文档、图片、音频、视频及上传/解析状态。
5. Vault：local-only、cloud、hybrid 策略和容量。
6. 同步中心：任务、冲突、设备、失败重试。
7. 设置：服务器、凭据、账户、隐私、安全、外观。

## 自适应布局

- Windows/宽屏：NavigationRail + 内容区；对话页支持会话列表、消息区和上下文侧栏。
- Android/窄屏：NavigationBar + 抽屉；详情页使用独立路由。

## 安全边界

- 服务器 URL 可以配置，默认 `https://sumeme.mv3.cn`。
- Gateway/API 凭据只保存在 Android Keystore 或 Windows Credential Manager。
- 客户端不包含服务端管理员令牌、Docker 凭据或中转站密钥。
- 当前生产身份仍需从 legacy 模式迁移为可信用户会话；迁移完成前，私有对象和管理 API 不应面向未受信客户端开放。

## 服务端 Web UI

服务器根页面提供 SuMeMe 管理后台，包含：

- 总览和服务健康；
- Vault 策略；
- 记忆检索和检查点；
- 文件/对象状态；
- 模型与供应商状态；
- 部署、磁盘、备份和审计占位；
- 账户与设备占位。

危险操作在管理员认证、二次确认和审计日志完成前保持禁用。
